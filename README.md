# SpendWise 💰

SpendWise is a web-based personal finance management system that helps users track income and expenses, manage categories, and analyze financial trends through interactive dashboards.

## 🚀 Features

- User Authentication (Login & Register)
- Expense Management (Add, Edit, Delete)
- Category Management
- Dashboard Summary
- Weekly & Monthly Analytics
- Top Spending Insights

## 🛠 Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP (Apache Server)

## 📊 Project Objective

To provide users with a simple and efficient platform for tracking personal finances and analyzing spending behavior.
